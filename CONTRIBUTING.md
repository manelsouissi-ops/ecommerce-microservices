# Guide de contribution

## Organisation du travail

- Manel Souissi : API Gateway, documentation, Docker
- Mohamed Raed : Microservices, Kafka, bases de données

## Branches utilisées

- `main` : branche principale
- `feature/api-gateway` : développement de l'API Gateway

## Convention des commits

- `feat:` nouvelle fonctionnalité
- `fix:` correction de bug
- `docs:` documentation
- `init:` initialisation
